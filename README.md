# Pop Mart Toys E-commerce Page

This project is a simple one-page marketing website for Pop Mart toys, focusing on blind boxes. It's designed to be a modern, cross-border e-commerce page.

**Features:**
*   English language
*   Modern UI (using Tailwind CSS)
*   jQuery for potential interactivity
*   WhatsApp integration for customer contact
*   Focus on blind boxes as the main product
